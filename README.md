# 圆内翻滚

正方形沿圆内壁无滑动滚动一周时，顶点 A 的轨迹。

打开 [GitHub Pages](https://tangobearwiki.github.io/rolling-square/) 即可播放。

## 题目

圆 O 半径为 2，内有边长为 2 的正方形 ABCD。初始时边 AB 作为圆的弦紧贴内壁。将正方形沿顺时针方向无滑动翻滚（每次翻转后均有一条边贴壁），直到贴壁圆心角累计达到 \(2\pi\)。求顶点 A 走过的路径总长。

## 结论

- 总翻转 6 次，支点依次为 \(B \to C \to D \to A \to B \to C\)
- 每次绕顶点在实验室系中转过 \(\pi/6\)
- 顶点 A 的六段弧长：\(\pi/3,\ \pi\sqrt{2}/3,\ \pi/3,\ 0,\ \pi/3,\ \pi\sqrt{2}/3\)
- 路径总长

\[
L = \frac{\pi(3 + 2\sqrt{2})}{3} \approx 6.1035
\]

## 操作

- 空格：播放 / 暂停
- ← / →：逐步翻转
- 轨迹、半径、循环可在底部开关
