圆内翻滚

边长 2 的正方形在半径 2 的圆内无滑动翻滚，以几何 C 点为轨迹重点，A 点保留在 D 点右侧。

题目

圆 O 半径为 2，内有边长为 2 的正方形 ABCD。当前动画中 A 保留在 D 点右侧的顶点；红色轨迹重点追踪几何 C 点。初始正方形的一条边为圆 O 的弦。正方形沿顺时针无滑动翻滚，每次翻转后都有一条边贴壁，直到贴壁圆心角累计达到 2π。求 C 点走过的路径总长。

几何

  • 弦长 2、半径 2，故圆心角 ∠AOB = 60°，弦心距 √3。
  • 绕顶点翻到下一边贴壁时，正方形相对实验室系转过 90° − 60° = 30° = π/6。
  • 每次贴壁推进 60°，6 次恰好一周。按当前标注，支点依次为 D → B → A → C → D → B。
  • A 到支点的距离只可能是 0、边长 2，或对角线 2√2。

路径总长

L = π(2 + √2) / 3

L = 2 · (π/3) + π√2 / 3 = π(2 + √2) / 3。第二次绕 C 自身翻转，C 静止，贡献为 0。
